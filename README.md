LearnSmart je inteligentna učna platforma, ki s pomočjo umetne inteligence prilagaja učne vsebine posameznemu uporabniku glede na njegov učni stil po modelu VARK.

Platforma omogoča generiranje personaliziranih učnih gradiv, kvizov in zvočnih vsebin iz naloženih izobraževalnih virov ter spodbuja učenje z elementi igrifikacije.
