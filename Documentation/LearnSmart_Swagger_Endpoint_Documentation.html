LearnSmart Backend API (1.0)

Download OpenAPI specification:Download

REST API for the LearnSmart platform. All endpoints except /health and /ai/classify-style require a Supabase JWT token.

Auth

User identity and registration endpoints — JWT Bearer required

Complete user registration

Sets the username and role (ucenec/ucitelj) on the user's Supabase profile. Called once after first Google OAuth login.

Authorizations:
bearerAuth
Request Body schema: application/json
required

Username and role selection

string

Responses

Generated server url

http://localhost:8081/api/me/complete-registration

Request samples

  • Payload
Content type
application/json
{
  • "username": "janez",
  • "vloga": "ucenec"
}

Get current user

Returns basic identity claims from the Supabase JWT (id, email, full name).

Authorizations:
bearerAuth

Responses

Generated server url

http://localhost:8081/api/me

Delete current user

Deletes the authenticated user from Supabase Auth and their profile data.

Authorizations:
bearerAuth

Responses

Generated server url

http://localhost:8081/api/me

Get user registration status

Checks Supabase whether the user has completed registration (set username + role). Returns isNewUser=true if the profile is incomplete.

Authorizations:
bearerAuth

Responses

Generated server url

http://localhost:8081/api/me/status

Get XP leaderboard

Returns all students ranked by total XP descending. The current user is marked with isMe=true.

Authorizations:
bearerAuth

Responses

Generated server url

http://localhost:8081/api/leaderboard

AI

Gemini-powered learning style classification

Classify VARK learning style

Submits VARK questionnaire answers to Gemini AI and returns the dominant learning style. If a JWT is present, the result is persisted to the user's profile. Falls back to count-based classification if Gemini is unavailable. Authentication is optional — works for both logged-in users and anonymous calls.

Request Body schema: application/json
required

List of VARK answer strings from the questionnaire

string

Responses

Generated server url

http://localhost:8081/ai/classify-style

Request samples

  • Payload
Content type
application/json
{
  • "answers": [
    • "visual",
    • "reading",
    • "visual",
    • "kinesthetic"
    ]
}

Health check

Returns UP when the service is running. Used by Render for health monitoring.

Responses
